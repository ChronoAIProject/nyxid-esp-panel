# Electrical playback reference recovery between two generated code sequences

Use the frozen 400 ms external WAV, frozen C161 and the original microphone detector. Instrument the existing code to record the raw microphone match, the complete electrical-reference matches, the prefix state, the full veto interval and the final allowed marker on the four panel paths. Compare the allowed clocks with the archived P4 events. A second code sequence begins while the default reference matcher is in its 8,039-tick refractory period. Test 320 ticks (one 80 ms code at 4 kHz) on that complete electrical-reference matcher alone, with the original 3,488-sample suppression interval per match. Check the raw timings to establish whether a new match actually refreshes the veto.

Replay both synchronous and zero reference on the four panel paths and the 15 external player-rate cases in the native P4 guest. Compare the 96 historical interruptions and their 96 erased controls. Retain input identity, both receiver clocks, heap and UART evidence. For collisions also overlay the existing +5 dB external call and the 400 ms panel self-play in each geometry at source start offsets of −800, −400, 0, +400 and +800 ms. Use the same acoustic path/gain for each source in that geometry, clip once after summation, and send only the panel to the reference channel. Run both guests on the same new inputs and compare each first open to the raw external-alone and panel-alone decisions. These symmetric-path collisions expose both ambiguous calls and suppression of genuine external calls. The panel source begins after two seconds of silence in all cases. All timings are receiver samples at 16 kHz.
