# Official Willow with C161-length warmup

All 72 complete original consumed Piper Semaine synthetic clips finished in one sequential QEMU run. Official `wn9_heywillow_tts`, DEFAULT getter bits `3f24dd2f`, native 512-sample calls, 32256 firmware zero samples followed by 49344 continuous host zero samples, then unchanged source with no state reset. Total zero warmup is 81600 samples, matching C161's sample count but not its frontend or event rules.

Willow targets: bare 0/9, command 3/27, total 3/36. Reciprocal Nyx clips: 0/36 activations. All firmware and additional prime positive events: zero. No backgrounds were replayed; this run adds no FAR exposure. The prior 32256-prime official result was 4/36, so longer warmup did not solve recognition on this particular consumed synthetic source. No threshold was selected or changed.

Full saved native returns, their event reconstruction, source PCM hashes/CRC, runtime identity, threshold getter before/after firmware prime and completed stage were checked by `summarize_willow_c161_reference_v1.py`. Original first case completed inference but encountered a cross-device collection move failure; its original evidence was preserved and not inferred again. A later startup hash refusal performed no inference. Plan revisions and these interruptions remain in git/log history.

This source is not a representative test of everyday Willow use. Low synthetic recall could reflect voice/pronunciation/domain mismatch; this run does not identify the cause. Do not infer that C161 is superior or that a commercial wake detector is generally ineffective. In particular, correlated augmentations are not independent speakers and equal warmup sample count is not equal runtime architecture. Existing C161 legacy/Jenny/Melo results remain protocol-specific.

Next useful comparison needs a reference-positive source on which Willow actually recognizes the intended phrase, with pinned model/source and matched voice/carrier coverage. Reuse existing consumed native Mac speech witnesses to establish that positive control before expanding a new paired study; do not create more blind training variants to compensate for a reference voice failure. C161 improvements still prioritize cross-voice/accent commands and everyday conflicts rather than all constructed nearwords. Mac/P4 field feedback remains outstanding on Issue #18.
