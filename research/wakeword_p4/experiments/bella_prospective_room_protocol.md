# New synthetic-room comparison for an external generated call

Freeze the original 1.45 s Bella cue and its published +2 dB version. Compare them with the existing RMS-matched Bella Hey Willow recording at those two source gains. The 96 historical interruption trials already influenced the choice of +2 dB. This development test uses new room geometry and source placement generated after the cue was frozen.

Use NumPy PCG64 seed 318491 and 12 rectangular rooms. Sample width 3.5–7 m, length 4–8 m and height 2.4–3.4 m. Place the panel mic, external target speaker and competing speaker inside each room at least 0.5 m from a wall, at heights between 0.9 and 1.65 m. Calculate the direct path and all six first-order specular reflections with spherical spreading, 343 m/s sound speed and fractional-sample delays. Use independent wall pressure reflection coefficients 0.35–0.75. This simplified geometry is a digital early-reflection test. Keep physical panel playback silent. Add reproducible low-level microphone noise and one prior admitted synthetic conversational recording per room. Align its active center with the center of the address. For the competing-speaker condition use target-to-competing active RMS ratios of −6, 0 and +6 dB, rotating by room index, set using the original Nyx input. Also replay each room with the competing source muted. Preserve the noise and transferred command across the five tracks: original Nyx, +2 dB Nyx, original Willow, +2 dB Willow and erased address. Use each command and each interfering recording in its preselected order. Archive microphone, room and file digests.

Run the shipped standalone detector's P4 research guest and official Willow DEFAULT on each microphone. Score a first open between the direct-path address onset and direct-path command arrival as timely. Record misses, cross-word responses, blank controls, ADC clipping and any false open before the address. Keep the working points fixed for every room. These are new generated scenes using existing synthetic voices, with zero physical or independent background-hour exposure.
