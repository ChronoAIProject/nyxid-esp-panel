# C161 的合成元音与常用姓名配对训练

Mac 在单独播放的 BR “Hey Nicole…” 上确认原路、噪声估计替代路分别在样本 12960、13440 触发。本实验采用原始冻结 C161 做对照，用同一份模型中的 3480 个 INT8 输出层权重训练两个候选。保持原输出层偏置和整个量化 ABI。候选均可作为单路或双路的共享权重重放。

使用已划入训练分区的 Kokoro 1.0 声音。每条生成保存实际 16 kHz PCM、音素 ID、时长和源哈希。八个声音分成六个拟合声音与两个仅供本轮迁移观察的声音。历史 C161 已使用该来源，不能把这两个声音算作独立验收。每个声音、语速、载句都有 Nyx、Nick、Nicole 和带完整词尾的 Next。额外的目标只将 Nyx 中的 /ɪ/ 改成 /ɛ/，保留 /ks/，具体合成输出待转录检验。日常负例包括询问下一项和陈述 Nicole 持有文件。Joe 和 Mac 开发声音均不入训练。

两组使用相同训练预算和姓名、日常负例。对照组只用标准元音，实验组在同一目标槽位使用一半标准、一半变体。标准组与实验组使用相同伪随机抽样和优化器；起点为原 INT8  权重，固定更新 400 步。保留最终字节，以 235/256、五步平滑、67 步冷却检查候选。报告两组在迁移声音与已消费连续命令上的逐条得失、Nicole 原句、日常与 Joe。保留原始未解封验收材料。

## 实际训练与逐句回放

4090 合成 272 个完整原音。八个声音各用两种语速；每种语速含三种载句的五类称呼及两条日常句。所有转为 16 kHz PCM 的输入均无削波。保存实际送入合成器的完整音素和每个 token 的预测时长。Whisper 在标准 48 个目标中有 23 个转为以 “hey next” 或 “hay next” 开头，改变元音后为 34/48，48 个 Nicole 均转写为 “Hey Nicole”。这项解码记录不决定任何标签。[原音清单](../results/4090-c161-vowel-name-sources-v1.json) · [逐词转录](../results/4090-c161-vowel-name-asr-v1.json)

每组从冻结 C161 的同一原生 FC 层起步，204 个训练原音加固定 0.5 秒尾静音，以另 2557 个原训练时钟步约束 logit 漂移。首次读校准批的哈希时误读了计划文件的字段，在第一次优化前退出。改由原始批次回执验证同一文件后，两组各完成 400 次更新。两份模型各 60,952 字节。差异均在原权重缓冲区内。逐步使用主机两个独立解释器和原事件策略，涵盖 911 次输入回放/模型（147 个上下文输入、272 个生成输入、24 次 Willow 对照、96 条日常负例、12 个 Mac 片段、360 个 Joe 片段）。[两组权重绑定与训练损失](../results/4090-c161-vowel-name-training-v1.json)

仅用于本轮迁移观察的两个声音，在标准目标上从 7/12 到 12/12、12/12；变体目标从 0/12 到 6/12、10/12；但 Nick 从 0/12 到 2/12、3/12，Nicole 从 0/12 到 2/12、2/12。结合日常语句与真实连续顺序，暂不推荐这两份模型作为板端替代。训练窗为合成前缀后 30 至 270 ms，单独播放的命中以完整片段及 0.5 秒尾窗里的事件计数。[生成材料逐条结果](../results/4090-c161-vowel-name-generated-v1.json)
