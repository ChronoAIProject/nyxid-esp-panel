# Fixed pronunciation-unit auxiliary experiment proposal

Saved direct character INT8 output has no Y token in any synthetic stream and often renders the keyword as H/HIS/HICS/HIKS. Character edit rates against intended generator text are 54.30% legacy, 53.29% Jenny, 53.24% Joe. This establishes incomplete deployed orthographic decoding, not a quantization fault, training-set failure, or causal diagnosis. No spelling aliases, matching-rule relaxation, beam search or checkpoint rescue is justified by these results.

A distinct hypothesis is that orthographic CTC asks a tiny encoder to emit redundant letters such as CK and Y from sounds with no separate corresponding segment. Fixed pronunciation-codepoint supervision could present a more acoustically related target. This is a label-unit intervention, not merely a larger loss coefficient, longer training or a claim that pronunciation correctness is known. The bundled Piper/eSpeak en-us lexicon maps HEY NICKS to `heɪ nɪks`, NICK to `nɪk`, NEXT to `nɛkst`, MIX to `mɪks`, preserving the distinguishing consonants/vowels. The target still has a right-continuation ambiguity and does not solve it automatically.

Implemented causal_phone_supervision_v1.py reuses existing complete training inputs and original generator text only. It uses existing piper_phonemize; no waveform generation or new installation. Lexicon records package/native/library/data hashes, fixed en-us voice, no stress/sentence punctuation, and spaces/length markers retained. Labels are Unicode IPA codepoints, explicitly not a claim of atomic phonemes or speaker-specific true pronunciation. It covers all 45 strings observed in the retained character supervision sample; unseen training strings fail explicitly. Twelve batches exercise 80 known synthetic/48 unknown ambient per batch, all available CTC lengths fit. Ambient stays excluded from sequence labels and retains binary BCE. No fresh development/final inputs are accessed.

Next training, if implemented, must start from the original initializer (not rescue the failed final checkpoint), keep source-balanced inputs/seed726, frozen BN, original binary BCE and coefficient-one length-normalized CTC, and the same final-only 20000 RTX4090 update budget. Only target units and the corresponding 32-class seeded head change from the character auxiliary recipe. Primary deployed candidate remains the original binary readout; no posthoc selection between binary and sequence heads. A separate execution lock must be pushed before training. Full actual-waveform deployment evidence remains required, and independent operating-point/qualification remains unresolved. Neither this label implementation nor a lower training loss qualifies a model or replaces frozen v30.
