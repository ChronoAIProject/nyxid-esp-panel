# Fit the three generated code stems to multiple player speeds

Keep the published +5 dB voice and frozen receiver. Modify only the synthetic marker contribution. Form three versions of each original code by time-scaling around the middle code's center at 0.99, 1.00 and 1.01. Use a preparation window that contains all versions of that code. Normalize each proposed blend to the energy of its original code. On the RTX 4090 fit nonnegative mixture weights summing to one for each code using only the isolated stems. Maximize the weakest cosine similarity against the three target versions, using 160 fixed Adam steps at learning rate 0.04 and soft-min temperature 0.04. Freeze the last step. Preserve the original length, address onset and command boundary. If any sample exceeds PCM16, reject the candidate.
