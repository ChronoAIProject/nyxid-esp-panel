# Separate deployed greedy character decoder experiment

The completed auxiliary experiment (binary INT8 SHA 446f56e7...) failed its behavior comparison; its discarded head never participated in wake decisions. This separately registered experiment tests direct ordered decoding. It does not retroactively replace that result or select the better head for promotion.

Reuse only the fixed final 20000-update encoder and original final-character-head-variables.npz from the completed run. No retraining, coefficient changes, checkpoint choice, aliases, new audio, ASR labels or score-conditioned examples. Full generator text was used in training; intended orthography is not phonetic truth. Unknown ambient speech had no character labels, so background rejection is unproven and must be measured on complete streams.

Export a distinct builtin INT8 streaming character model: same causal frontend/context309/stride3 and frozen normalization, 60-channel encoder followed by the existing 28-logit Dense head. Remove the binary readout and its history state; preserve the five encoder history states. Expected input [1,3,40], output [1,1,28], integer tensors. Preserve final head bytes and source hashes in a new export lock before conversion. Use the previously fixed representative sequence, no calibration retry. A single functional replay establishes operation only, not numerical agreement or recognition.

Decoder protocol implemented in causal_character_decoder_v1.py: choose argmax over the 28 quantized logits (lowest token ID wins ties), standard greedy CTC collapse (blank zero; identical consecutive IDs collapse, intervening blank permits repetition). Fixed alphabet ` ABCDEFGHIJKLMNOPQRSTUVWXYZ`. Match exactly `HEY NICKS` at stream start or after a decoded space; no aliases, beam, confidence threshold, binary gate/fusion, smoothing, endpoint oracle or finish flush. Emit immediately on the final decoded S, preserving all model/CTC/matcher state after an event. A right-hand continuation such as NICKSON can therefore trigger: explicitly a protocol limitation, not hidden postprocessing. Reset model and decoder together only at a new independent stream. Decode all 81600 prime samples, preserve events/state across the source boundary, ignore only prime notifications in application metrics. Do not reset a partial prime keyword at the boundary. Actual input tails follow the existing collector, with no additional finish zeros or decoder flush.

The scalar binary threshold .91796875/smoothing5 remains the frozen binary reference; it has no meaning for argmax decoding and must not be misrepresented as applied to this decoder. No output-based protocol adjustment. Evaluate the same consumed legacy/Jenny/Joe full waves and full backgrounds once, preserving every decoded event including prime and tails. Compare saved binary and official native results with their intrinsic clocks/policies stated; direct decoder is a different deployment mechanism, not a matched binary operating point or independent acceptance. No model promotion or Mac replacement follows from this screen. Independent operating-point/qualification requirements of the full goal remain unresolved.

Five functional protocol tests pass: continuous command/repeated keyword, nearword/left boundary rejection, CTC repeat/blank handling, no implicit source-boundary reset, and documented right continuation. These exercise the actual state machine, not learned acoustic accuracy. Next concrete work is the separately locked INT8 character export and complete-wave behavior screen, with no new training.
