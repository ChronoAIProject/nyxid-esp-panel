# 连续前文与五步事件的配对输出层训练

从冻结 C161 原 INT8 出发。在六个已许可训练的 Kokoro 声音、两个语速和三个载句中，每组取完整标准 Nyx、Nick、Nicole 和 Next，再加一条既有训练分区的日常数词句。使用同一段训练对话前文、相同间隔与相同输入相位重放每组五条 PCM。两个训练条件分别使用该前文和等长静音。两条原生前端都按全程连续时钟产生输出层输入。Joe、Mac 和两个迁移观察声音只参与开发回放。

每组五条依原 C161 选择连续五步训练窗口。正例窗口以目标合成词尾为基准，在词尾后 0 至 180 ms 结束。四种负例分别选取自身最强五步窗口。训练显式要求目标和最强同组负例拉开距离，用原训练校准特征限制输出漂移。两组均用同一随机种子和最终第 400 步，各输出一份原 ABI 的 INT8。此设计同时测定时序配对训练的结果以及有声前文相对静音的增量。它与历史前文混合训练的区别包括对应姓名、两条实际前端以及同组五步竞争。

在原协议的连续与独立命令、日常 96 句、Joe、Mac、同前文 Hey Willow 和合成最小对上，使用原双解释器、五步阈值 1175 和 67 步冷却核对。按同句分别报告找回与丢失、BR Nicole、six cups、通知相对首命令音素的时间。Mike 继续封存。
