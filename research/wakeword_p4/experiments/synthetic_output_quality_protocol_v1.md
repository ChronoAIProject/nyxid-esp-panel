# Mechanical synthesis output gate v1

This component gates native TTS output and its16k PCM transport. It is not a
complete development/acceptance reservation and reserves no new voice. No new
source may be scored under this document alone. Existing consumedSLR83 is used
only to exercise the validator; its role and earlier failed candidate results
are unchanged. Current recovery training uses the already frozen old inputs,
not data filtered or regenerated by this gate.

Before new generation, a source-role plan must pin exact model/config bytes,
original URL/revision, voice and speaker ID, engine/runtime versions, input
text/phonemes/token IDs, native rate, scales and each requested draw. Record
training/development/acceptance roles before generation; unknown physical
speaker/pretraining overlap remains explicit. No human listening prerequisite.

The generator must save the entire native waveform return immediately as
float32 NPY, before any transformation. Preserve its output shape, file SHA
and number of samples. Save native durations/alignments when exposed; otherwise
store null and name the unavailable interface. Never invent token timings or
claim an unexposed ONNX random seed. Preserve actual output bytes when the
engine contains stochastic operators. A reproducible procedure does not imply
bitwise re-generation.

No trimming, posthoc gain, normalization, clipping repair or score-based
regeneration. Resample the complete vector by scipy.signal.resample_poly with
the exact integer16000/native-rate ratio and save mono PCM16 WAV. Pin versions
and raw/WAV hashes in each source record. Native and resampled samples must be
finite and abs<1; PCM16 must have no saturated endpoints. Full transported
length must equal ceil(native_samples*16000/native_rate), and every sample
must match the complete resample within1/32768+1e-7 quantization tolerance.
Require nonzero output, duration0.2..5s and RMS>=0.001, matching prior
mechanical synthesis limits. Ledger hashes, lengths and the untrimmed output
end reference must agree. Missing files/hash or invalid arrays are errors,
not passes; all check failures remain visible.

Implementation:synthetic_output_quality_v1.audit_output. The retrospective
audit additionally authenticates model/config/source/generator hashes, original
versions, planned text, saved phones/token mapping and unavailable duration
metadata. It does not synthesize or invoke detectors. Six analytic adversarial
tests cover correct22050->16000 transport, a cropped PCM with adjusted ledger,
changed gain, silence/clipping, nonfinite native and replaced native bytes.
Fixtures are test signals only, never speech/acceptance evidence.

For a future role reservation, freeze all expected records and quality failure
handling before generating. A failing requested source/draw must remain in
the report and stops that planned pack from being declared qualified; do not
silently discard it or substitute another draw after detector scores. Any new
plan must retain the failed plan and explicitly describe its changed source
policy before generation and without detector-based selection.

This proves saved-output and transport integrity, not that the TTS engine
uttered the intended phonemes or finished a semantic phrase. The authenticated
generator supports whole-return provenance but cannot reveal hidden decoder
truncation. Generated-output end is a synthetic latency reference only.
Augmented waveform gates still need separate full-source placement, complete
RIR convolution tails, noise/gain provenance and end-boundary checks in the
new reservation. Voice-role independence, background reservation, threshold
selection, officialHiESP/v30 same-PCM streaming and independent acceptance
FAR95<=0.5/h remain separate mandatory requirements; this gate does not
authorize promotion or assert those requirements are done.
