# Single-model multiscale causal readout: structural investigation

Shorter-span's float regressions rule out an INT8-only explanation: replacing the long path removes useful voice/command support while helping some connected contexts. A distinct hypothesis is to retain the original306frame backbone and expose its existing intermediate temporal scales directly to one learned binary readout. This does not assume that shorter-span successes transfer, nor that either architecture identifies the exact failure cause.

Fixed design: original64channel stem and five residual blocks with dilations1/2/4/8/10. Concatenate the stem and all five residual outputs,384channels, before the existing causal two-call binary head. There is one logit, one sigmoid and one event decoder, not six deployed detectors or a fourth parallel expert. No max/OR of trained parents, no frozen candidate bank or score-calibrated gate. One head state384 instead of64, all six backbone caches unchanged: logical float-state elements6544→6864. Head parameters129→769, total30593→31233; convolution MAC/call29888→30528. Maximum receptive field remains306frames; direct head paths have6/18/42/90/186/306frame support. These scales are consequences of the original fixed backbone, not a span sweep. Adaptive frontend history persists.

This differs from the historical nonlinear3480→16→1 flattened scalar readout: that changed the scalar architecture's output nonlinearity and capacity. This design keeps Binary40's temporal backbone and uses a linear head across existing intermediate scales. It also differs from the failed width128 intervention, shortened dilation pair, context/teacher objectives and third-expert event policy. All those failed identities remain preserved. This proposal is informed by consumed diagnostics and is exploratory, not independent acceptance evidence.

Before optimizer work: implement one fixed architecture, independently enumerate dependency supports/state/parameters/MACs, verify same-seed backbone tensors against original, exact original function when shallow head coefficients are zero and deepest head weights copied, full/chunk/native-step parity, causality and state reset. Verify finite gradients and no parameter changes on original training-only batches. Then separately inspect builtinINT8 conversion/cache feedback feasibility. No human recording, board, newTTS, source mining or heldout inspection. Do not train, tune head subsets/scale counts or promote from structural checks.

Only if those engineering checks pass may a separate formal execution lock define a fresh matched control/treatment, unchanged original main sampling/labels/BCE/optimizer/budget/final-only protocol, full original cohorts and context streams. New head initialization must be fixed prospectively and its control initialization implications disclosed; do not silently warm-start final models. Preserve C161 baseline and Mac dual/triple packages. Actual P4 memory/realtime/first-command/stability requirements remain, and the broad goal stays active.
