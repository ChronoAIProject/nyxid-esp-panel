# Estimate the end of the fixed address at microphone open

Use the published three-triplet WAV, the 24 original-level Surrey calls with full simulated peer sends, and the 12 candidate inputs from 60° and 210° for a timing check. The command immediately follows the 23,200-sample address in every issued stereo program. At the actual first open, match the first 6,400 samples of the isolated cue against the raw microphone, searching starts from one cue duration before open to the last alignment whose prefix has already been captured. Select the largest absolute energy-normalized correlation, then add the fixed cue duration. Report the estimated minus annotated command start for every input, including low-correlation and mistimed cases. Neither the room response nor the command annotation enters the estimate.

For the 24 available paired sends, begin the ASR input 1,600 samples (100 ms) before the estimate. Map this to the received Opus clock using the captured FIFO start and the number of sent silence frames from that schedule. Compare against the complete, previously decoded send, verified by PCM hash. Use both registered GPU readers, immediate and delayed readiness, an exact normalized command suffix and an exact whole-transcript command. The whole-transcript measure counts any extra words, including the address. Keep the complete transmitted bytes and all 24 cases. This is a receiver-side diagnostic for external fixed-WAV playback followed immediately by a command.
