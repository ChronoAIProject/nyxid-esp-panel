# Transfer of the released two-speaker player files to two Aachen spaces

Use the Aachen Impulse Response (AIR) database as distributed in OpenSLR 28. Select the two rooms with paired 0° and 180° right-channel binaural responses used here, the stairway (condition 1, position 1) and Aula Carolina (condition 1, position 3, configuration 3). Treat the labels as source azimuth indices. Use the right channel at 16 kHz from all four WAVs. Normalize both directions in a room by the L2 norm of its 0° response. This fixes an arbitrary room-level scale while preserving the relative gains of the distributed response files. Use the maximum absolute response sample in the first 50 ms as the direct-arrival estimate, and report its position. [AIR database](https://www.iks.rwth-aachen.de/en/research/tools-downloads/databases/aachen-impulse-response-database/) · [OpenSLR 28](https://www.openslr.org/28/)

Play the released stereo pack with SHA256 `d349ac1157307ed47851e5f4e287e8c69d634862cb817ab21b4365f260fdf287`. Left is the target player and right the opposite interruption. In each room test both target directions, three original commands, both released player levels and all four variants A, B, Willow and address-erased. Use one Gaussian microphone noise draw at 12 PCM16 counts RMS per room, direction and command using NumPy PCG64 seed 209473. Compute the two convolutions in float64 on RTX 4090, using all available response taps, and verify the digitized samples against single-thread SciPy. Record from stereo sample zero through the entire dry file and another 1.25 s. The fixed observation length includes the original quiet tail and bounds the QEMU input. Save any saturation counts. Feed the same microphone and silent electrical reference to the two registered receivers, retaining raw counts, timely openings and reciprocal and erased controls.

For each intended address and level use the first actual open to replay the full capture, Opus and sender path. Score the complete target command using the same unprompted Qwen / Whisper readers with immediate and delayed readiness. Retain missed wakes in all denominators. The 96 waveforms use three consumed synthetic command and interruption pairs. These results measure transfer of the two frozen player WAVs to two additional room-response pairs. The sources and thresholds were fixed before this comparison.
